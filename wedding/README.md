# Rajesh & Chinmayee — Wedding Website

Two versions of our Odia wedding website.

| Folder | Look |
|---|---|
| `website-1/` | Rich plum and wine theme, Odia-inspired |
| `website-2/` | Sleek near-black theme with cream text |

Each folder is a complete, self-contained site. Open `index.html` in a browser,
or host the folder on GitHub Pages, Netlify or Vercel.
